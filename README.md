# Java Hangman Game

A console-based Hangman game built with Java as a practice project.

## 📌 Features

- Interactive console gameplay
- Word guessing
- Attempts tracking
- User input handling
- Game completion and result messages

## 🧠 Concepts Practiced

- Java fundamentals
- Loops and conditions
- Strings and characters
- Arrays or collections
- User input
- Basic problem solving

## 🛠️ Built With

- Java
- IntelliJ IDEA
- Git & GitHub

## 🎯 Purpose

This project is part of my Java learning journey and was created to practice programming fundamentals through a small working application.
